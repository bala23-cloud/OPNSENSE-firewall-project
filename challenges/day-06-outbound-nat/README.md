# Day 06 — Outbound NAT

**Status:** Planned — practical validation not yet recorded.

## Scenario
A small company needs to strengthen its network security while keeping business services available. This day's lab focuses on outbound nat.

## Objective
Understand how internal clients reach external networks through address translation.

## Lab plan
Review interface assignments and routing; inspect automatic/manual outbound NAT mode; document translation rules before changing them.

## How it will be validated
From an internal client, test outbound connectivity; compare source addresses before and after translation using firewall states or packet captures.

## Key lesson
NAT translates addresses; it does not replace firewall filtering.
