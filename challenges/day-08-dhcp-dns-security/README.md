# Day 08 — DHCP and DNS Security

**Status:** Planned — practical validation not yet recorded.

## Scenario
A small company needs to strengthen its network security while keeping business services available. This day's lab focuses on dhcp and dns security.

## Objective
Control client addressing and name resolution.

## Lab plan
Review DHCP scopes, reservations and gateway/DNS options; configure a trusted DNS resolver path; document client DNS settings.

## How it will be validated
Renew a test client's lease; verify address, gateway and DNS; test allowed and blocked name resolution and inspect logs.

## Key lesson
Incorrect DHCP or DNS settings can look like a firewall outage.
