# Day 09 — Firewall Log Analysis and Monitoring

**Guide status:** Documentation complete. Practical validation has not yet been recorded.

## Scenario
A small company needs to strengthen its network security while keeping business services available. This day's lab focuses on firewall log analysis and monitoring.

## Objective
Investigate traffic using firewall events and rule context.

## Lab plan
Generate controlled allowed and blocked test traffic; inspect live and historical firewall logs; correlate interface, source, destination, protocol, port and rule.

## How it will be validated
Repeat tests and confirm that each event matches the expected rule; retain redacted screenshots or text output.

## Key lesson
A log entry is useful only when correlated with the test and the rule that handled it.

## Notes
This challenge will be marked completed only after the configuration has been performed and the relevant tests have been observed. Add actual commands, screenshots, log extracts and troubleshooting notes after the practical. Do not publish credentials or sensitive network details.
