# Day 11 — High Availability and Failover

**Guide status:** Documentation complete. Practical validation has not yet been recorded.

## Scenario
A small company needs to strengthen its network security while keeping business services available. This day's lab focuses on high availability and failover.

## Objective
Understand how a backup firewall can take over when the primary fails.

## Lab plan
Study CARP, configuration synchronization, interface requirements and shared virtual IP design; identify whether the current VirtualBox lab can support two firewall VMs.

## How it will be validated
If resources permit, perform a controlled primary-failure test and measure gateway continuity; otherwise document the design as planned only.

## Key lesson
High availability needs coordinated configuration, compatible interfaces and a tested failover path.
