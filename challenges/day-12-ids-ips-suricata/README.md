# Day 12 — IDS and IPS with Suricata

**Guide status:** Documentation complete. Practical validation has not yet been recorded.

## Scenario
A small company needs to strengthen its network security while keeping business services available. This day's lab focuses on ids and ips with suricata.

## Objective
Detect suspicious traffic and understand prevention trade-offs.

## Lab plan
Review Suricata interface selection, rule sources, alert-only mode and IPS inline requirements; enable only in an isolated lab after checking resources.

## How it will be validated
Generate safe test traffic or use approved test signatures; verify alerts first, then evaluate blocking only if the topology supports it.

## Key lesson
Detection and prevention are different; an alert does not prove traffic was blocked.
